# Optional add-ons

- [tex-to-markdown](tex-to-markdown/SKILL.md): conservative LaTeX-to-native
  Markdown–TeX conversion script and agent skill. This is an opt-in bootstrap,
  not part of the Markdown parser or a general TeX interpreter. It has no
  dependency on an LLM service or on Pandoc. Review and compilation remain
  necessary, especially for custom macros and environments.
